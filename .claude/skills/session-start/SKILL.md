# session-start — обгортка

Повні інструкції цього скіла лежать в єдиному джерелі: `skills/session-start/SKILL.md` (шлях від кореня
репозиторію; від цього файлу — `../../../skills/session-start/SKILL.md`).

1. Перш ніж діяти, прочитай `skills/session-start/SKILL.md` повністю і виконуй його як інструкції цього скіла.
2. Допоміжні файли (напр. `references/`) лежать поруч із ним у `skills/session-start/` — відносні
   шляхи з канонічного SKILL.md рахуй від цієї теки.
