# Меню Chakra/Ark у браузері wmux: лише клавіатурою

## Коли застосовувати
Агент у браузері wmux відкриває меню застосунку (напр. «⋮» біля пошуку → «Плюси та мінуси»), а пункт меню не
спрацьовує або його не видно в знімку сторінки.

## Що робити
- Відкрити меню кліком за ref (`browser_click` на кнопці, напр. «Дії з пошуком» у знімку з `selector: "[role=dialog]"`).
- Далі — клавіатура: `browser_press_key` `ArrowDown` до потрібного пункту, потім `Enter`. Підсвічений пункт видно
  через `browser_evaluate`: `document.querySelector('[role=menu] [data-highlighted]')?.textContent`.
- Звичайні кнопки й чекбокси (не пункти меню) у вікнах застосунку натискаються й через `browser_evaluate` + `.click()`
  (для чекбокса — клік по його `label`).

## Чого не робити
- Не викликати `.click()` чи синтетичні `PointerEvent` на `[role=menuitem]`: меню закривається, дія не виконується.
- Не шукати пункти меню через `browser_snapshot` з `selector: "[role=menu]"` — вони в порталі, знімок порожній.

## Як перевірити
Після `Enter` відкрилося очікуване вікно (заголовок у `[role=dialog] h2`).
