# Людині — лише абсолютні шляхи (PowerShell під іншим профілем)

## Коли застосовувати
Даєш людині команду чи інструкцію з шляхом до файлу (особливо файлу із секретом).

## Що робити
- Писати повний шлях від `C:\Users\dell\…`, а не `$env:USERPROFILE\…` чи `~\…`: PowerShell людини
  запущений від адміністратора під іншим обліковим записом.
- Після «зберіг» перевірити зі свого боку, що файл змінився (час зміни / довжина); якщо це файл із
  секретом — не виводити вміст ([secrets-in-sources](secrets-in-sources.md)).

## Чого не робити
- Не використовувати `$env:USERPROFILE`, `~`, відносні шляхи в інструкціях для людини.

## Як перевірити
Файл за абсолютним шляхом має свіжий час зміни.
