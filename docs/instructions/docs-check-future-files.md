# `docs:check` падає на шляхах до файлів, яких ще немає

## Коли застосовувати
Пишеш план у `docs/plans/` і називаєш файли, які з'являться під час виконання, — або `npm run check` упав на
`docs:check` одразу після створення плану.

## Що робити
- Перевірка (`scripts/check-doc-links.mjs`) шукає на диску кожен шлях у бектиках, що починається з `docs/`, `server/`,
  `web/`, `scripts/`, `skills/`.
- Майбутній файл називати без цього початку: `src/routes/http.ts` (сервер) замість повного шляху від кореня — або
  звичайним текстом без бектиків.
- Коли файл створено, шлях можна лишити як є: план після завершення йде в `old/`, де шляхи до коду не перевіряються.

## Чого не робити
- Не створювати порожній файл-заглушку лише заради зеленої перевірки.

## Як перевірити
`npm run docs:check` — 0 битих посилань.
