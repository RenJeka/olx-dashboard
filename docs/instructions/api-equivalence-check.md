# Звірка API до/після рефакторингу на реальних даних

## Коли застосовувати
Змінюєш серверний код «без зміни поведінки» (перенесення SQL, розділення модулів), а тести покривають не всі
відповіді — треба довести, що GET-відповіді на реальних даних не змінились.

## Що робити
1. Локальна БД — копія проду ([development](../development.md) §4); лише GET-запити (без сканів, AI, записів).
2. Скрипт-знімок у scratchpad: `fetch` переліку шляхів (списки, деталі, фільтри, 404) на окремому порту → JSON
   `{шлях: {status, body}}`. Значення, що залежать від часу (напр. `planValid`), нормалізувати.
3. «Після»: `PORT=3099 timeout 90 npx tsx src/index.ts &` у `server/`, дочекатись `/health`, зняти знімок.
4. Зупинити сервер за портом (PowerShell `Get-NetTCPConnection -LocalPort 3099` → `Stop-Process`): `timeout` у Git
   Bash процес node не вбиває.
5. «До»: `git stash push -u -- src` (лише `server/src`, щоб не зачепити чуже незакомічене), той самий запуск і знімок,
   зупинка, `git stash pop`.
6. Порівняти два JSON по ключах — розбіжностей 0; кількість відповідей і обсяг записати в план.

### Відповіді-файли (ZIP)
ZIP-пакети ручного режиму AI віддають POST-ендпойнти, і байти архіву щоразу інші (час у заголовках файлів), тож
знімок GET їх не покриває. Звіряти вміст:
1. Тимчасовий тест поруч із маршрутами (не комітити): `resetDb` → пошук і оголошення на кілька чанків → `app.inject`
   кожного `package.zip` → `readZip` (`server/src/test/zip.ts`) → імена й тексти файлів у JSON у scratchpad.
2. Прогнати його до змін і після, порівняти два JSON (`cmp`) — мають збігатися байт-у-байт.
3. Тимчасовий тест видалити; постійні перевірки складу пакетів — `server/src/routes/aiRoutes.test.ts`.

## Чого не робити
- Не запускати на `:3001`, де може працювати `npm run dev` людини ([local-dev-port-busy](local-dev-port-busy.md)).
- Не викликати ендпойнти, що пишуть у БД чи ходять в OLX / OpenRouter.
- Не робити `git stash` без шляху: сховає й файли людини поза задачею.

## Як перевірити
Скрипт порівняння друкує «різних: 0»; `git status` після `stash pop` — ті самі зміни, що й до звірки.
