# Посилання після перенесення плану в `old/`

## Коли застосовувати
План завершено й перенесено `git mv docs/plans/<план>.md docs/plans/old/` (конвенція — `AGENTS.md` → «Конвенції»),
посилання на нього треба виправити.

## Що робити
- `npm run docs:check` — правити лише файли й рядки, які він назвав.
- Відносні посилання всередині перенесеного плану стають на рівень глибші (`../parking.md` → `../../parking.md`);
  посилання з інших архівних планів на нього — `old/<план>.md` або `<план>.md` поруч.
- Шляхи в коментарях коду (`docs/plans/<план>.md`) — оновити окремою заміною лише по `server/src` і `web/src`.

## Чого не робити
- Не робити масову заміну по всьому `docs/` (`grep -rl … docs | xargs sed`): вона чіпає хендофи, а їх не правлять
  заднім числом ([rules](../rules.md) → «Хендофи»), і архівні плани — історичні знімки.

## Як перевірити
`npm run docs:check` — 0 битих посилань; `git diff --stat` не містить `docs/handoffs/`.
