# Turso MCP `create_branch` повертає таймаут, але гілку створює

## Коли застосовувати
Створюєш гілку-бекап чи копію БД через Turso MCP (`create_branch`) і отримуєш таймаут.

## Що робити
- Зачекати 1–2 хв і перевірити `get_database` / `list_branches`: гілка створюється асинхронно.
- Повторювати `create_branch` лише якщо гілки справді немає.
- Після створення — ввімкнути захист від видалення, якщо це бекап.

## Чого не робити
- Не повторювати `create_branch` одразу після таймауту: отримаєш `409` (вже існує).

## Як перевірити
`get_database` для нової назви повертає БД.
