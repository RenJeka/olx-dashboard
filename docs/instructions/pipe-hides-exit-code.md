# `cmd | tail` ховає код виходу

## Коли застосовувати
Запускаєш перевірку (`npm run check`, `docs:check`, тести) і обрізаєш вивід через `| tail`, `| head`, `| grep`.

## Що робити
- Запускати перевірку без пайпа і дивитись на код виходу; довгий вивід — у файл:
  `npm run check > "$TMP/check.log" 2>&1; echo "exit=$?"`.
- Якщо пайп потрібен (bash): `set -o pipefail` або `echo "${PIPESTATUS[0]}"`.
- PowerShell: після нативної команди — `$LASTEXITCODE`.

## Чого не робити
- Не вважати перевірку зеленою за останніми рядками виводу: код виходу пайпа — це код `tail`, тобто 0.

## Як перевірити
У звіті є явний `exit=0` самої команди перевірки.
