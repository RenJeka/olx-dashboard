# Свої поля оголошення в тестах сервера — через `insertListing`

## Коли застосовувати
Тест на тимчасовій БД потребує оголошення з конкретним заголовком, описом, ціною чи категорією (пре-фільтр
релевантності, пошук, промпт, автокатегорія).

## Що робити
- Передати поле третім аргументом: `insertListing(searchId, olxId, { title: 'iPhone 13' })`. Типовий заголовок —
  `item <olx_id>`; тест задає лише важливі для нього поля ([development](../development.md) §7).
- Поля, якого ще немає в `ListingRow` (`server/src/test/db.ts`), — додати туди, а не писати окремий `UPDATE`.

## Чого не робити
- Не дописувати дані окремим `UPDATE listings …` після вставки: раніше хелпер ігнорував `title` і так доводилося
  робити — тепер це зайве.

## Як перевірити
`SELECT title FROM listings WHERE olx_id = ?` повертає заданий заголовок.
