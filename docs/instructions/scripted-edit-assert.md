# Скриптова заміна мовчки не спрацьовує або видаляє не те

## Коли застосовувати
Правиш файли скриптом: Python `str.replace`, `sed` за номерами рядків, кілька замін одним прогоном.

## Що робити
- Кожна заміна — з перевіркою: `assert old in s` (або `s.count(old) == 1`) перед `replace`; скрипт має
  впасти, а не тихо пропустити.
- `sed -i 'N,Md'` — лише після `sed -n 'N,Mp'` на тих самих номерах; номери з попереднього виводу могли
  зсунутись.
- Після прогону — `git diff` по кожному файлу: змінено саме те, що задумано.

## Чого не робити
- Не робити серію `replace` без перевірок: 2026-10-04 одна із замін у тимчасових логах S17 не застосувалась
  (лог завжди писав би `matchMs: 0` — знайшов CodeRabbit), а `sed` за номерами видалив чужий рядок у
  `current.md`.

## Як перевірити
Скрипт падає на відсутньому шаблоні; `git diff` показує лише очікувані рядки.
