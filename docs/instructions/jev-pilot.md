# Пілот Jev vs LLM на пошуку (вартість + якість з ручною розміткою)

## Коли застосовувати
Треба перевірити, чи Jev ([jev](../jev.md)) дешевший і не гірший за LLM-рушій на конкретному пошуку, або
підібрати пороги / формулювання питань. План і висновки попередніх пілотів — [plans/jev-model](../plans/jev-model.md).

## Що робити
1. **Ключ:** `OPENROUTER_API_KEY` у `server/.env` (його ставить людина).
2. **Вибірка** у server/data/jev-pilot/sample.json (тека gitignored):
   - локальна БД: `npm run jev:pilot -- --export <searchId> --limit 200`;
   - прод: [prod-data-via-turso-mcp](prod-data-via-turso-mcp.md) (у вибірку додавати `url` — для посилань у розмітці).
   Пошук має мати `analysis_criteria`, інакше крок 2 не порівнюється.
   Перед новою вибіркою зберегти попередні файли пілоту в підтеку (напр. `ipad9/`), бо вони перезаписуються.
3. **Прогін:** `npm run jev:pilot` (опції: `--variants L,A1s,A1f,A2,B,UK`, `--limit`, `--model`,
   `--rel-threshold`). Коштує центи. Результат — `report.md`, `raw.json`, `disputes.md` у тій самій теці.
4. **Розмітка людиною:** `disputes.md` — лише розбіжності Jev (продові пороги) vs свіжий LLM, з посиланням на OLX.
   Людина пише `т`/`н` у `[ ]`.
5. **Сирий вхід/вихід кроку 2 на кількох оголошеннях** (діагностика пропусків): `npm run jev:probe -- --search <id>
   --mode cons|pros --top 30` (або `--ids a,b`) — лише SELECT, викликає продовий рушій і пише в server/data/jev-pilot/
   дослівні запит/відповідь, ймовірність по кожному критерію й модель збереженого аналізу (`referenceModel`).
   Для перегляду — live artifact етапу 3 (посилання в плані).
6. **Підсумок:** порахувати, хто правий (Jev / LLM) окремо для кроку 1 і 2, і для порогу 0.5 перевірити
   діапазон 0.5–0.7 у `raw.json` (там можуть бути нерозмічені розбіжності). Висновки — у план, цифри — у хендоф.

## Чого не робити
- Не вважати «збіг з LLM» якістю: збережені й свіжі LLM-відповіді самі помиляються — еталон лише ручна розмітка.
- Не порівнювати вартість без урахування синонімів пошуку: Jev оплачує їх у кожному запиті.
- Не брати збережений аналіз за еталон, не глянувши `listings.analysis_model`: його міг зробити сам Jev (так було з
  «macbook m1» 2026-10-06) — тоді «збіг» означає порівняння Jev із собою. Свіжий еталон — LLM-прогін або ручна розмітка.

## Як перевірити
`report.md` має вартість для кожного варіанту без помилок запитів; у `disputes.md` усі `[ ]` заповнені.
