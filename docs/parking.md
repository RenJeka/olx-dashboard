[templates/parking-entry.md](templates/parking-entry.md), правила нумерації й закриття — у
[rules.md](rules.md) → «Парковка». Скіл для запису — `parking-add`.

- Що: по кліку на рядок/посилання показувати сторінку оголошення OLX у вбудованому вікні, без переходу.

- Коли повернутися: у вікні UI-покращень.
