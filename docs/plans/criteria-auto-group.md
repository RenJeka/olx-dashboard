# Автоматичне групування критеріїв у категорії

> **Статус:** 🟢 активний · план схвалено 2026-10-11 (людина: «так», починати з нього) · продовження [criteria-categories](criteria-categories.md)

## Контекст

- Зараз категорію створює лише людина: галочки → «Об'єднати в категорію…» (`POST /criteria/remap`).
- Людина (2026-10-11): кнопка, за якою система сама пропонує, що об'єднати; результат — у вікні, як після
  «Згенерувати»: прийняти все, частину (одні об'єднати, інші лишити окремими) або нічого.

## Рішення (пропозиція, підтвердити)

| Питання | Пропозиція |
| --- | --- |
| Де кнопка | Вікно «Плюси та мінуси», поруч із «Згенерувати»: «Згрупувати автоматично» (для поточної вкладки). Видно, коли є ключ OpenRouter і ≥ 2 критерії |
| Хто пропонує | LLM (модель з налаштувань); Jev не вміє — він лише відповідає «так/ні». Один запит на натискання, критерії без оголошень → < $0.001 |
| Що йде в промпт | Назви категорій і окремих критеріїв поточного режиму з синонімами. Без описів оголошень і PII |
| Що повертає | `{"groups": [{"name": "…", "members": ["…", "…"]}]}` — лише групи з ≥ 2 членів; `name` — один із членів або нова коротка назва |
| Перевірка в коді | Член має бути в списку (без урахування регістру); один член — в одній групі; групи з < 2 членів відкидаються; назва ≤ 6 слів, не збігається з критерієм поза групою |
| Застосування | Одна транзакція для всіх обраних груп: `POST /criteria/remap` приймає ще й `merges: [{from, to}]`; `recomputeFilteredOut` — один раз (Turso-економія). Старий формат запиту лишається |

## UI

```
┌ Запропоновані категорії · Мінуси ──────────────── ✕ ┐
│ ☑ [дефект екрану_______]          зачепить 41 огол. │
│     ☑ тріснутий екран  ☑ зламаний екран  ☐ засвіт   │
│ ☑ [б/в стан____________]          зачепить 37 огол. │
│     ☑ експлуатований  ☑ б/в стан                    │
│ Решта критеріїв лишаються окремими.                 │
├─────────────────────────────────────────────────────┤
│              [Не об'єднувати] [Об'єднати обрані (2)] │
└─────────────────────────────────────────────────────┘
```

- Галочка групи — прийняти/відхилити групу; галочка члена — лишити його окремим критерієм; назву можна змінити.
- Група, де лишився < 2 членів, вимикається сама. Якщо пропозицій немає — тост «Нічого об'єднувати».
- Закриття — лише хрестиком, Escape чи «Не об'єднувати» (як інші вікна, `NestedDialog`).

## Test-cases

1. Vitest: пропозиція з невідомим членом — член відкинутий; член у двох групах — лишається в першій; група з одного
   члена — відкинута; `merges` з двох груп — один прохід по оголошеннях, обидві категорії в списку.
2. Вручну (людина, платно < $0.01): «Плюси та мінуси» → «Плюси» → «Згрупувати автоматично» → у вікні зняти одну групу
   → «Об'єднати обрані» → у списку з'явились лише прийняті категорії.
