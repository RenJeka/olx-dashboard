## Test-cases

- `npm run check` зелений після `npm audit fix`; `npm audit --omit=dev` — лише задокументовані залишки.
- Проба HTML-fallback повертає оголошення (або fallback свідомо вимкнено й задокументовано).
- Після деплою: фронт відкривається, логін працює, скан пошуку проходить.
