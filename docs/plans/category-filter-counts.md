# Зрозумілі лічильники у фільтрі «Категорії»

> **Статус:** 🟢 активний · гілку створити від `main` (2026-10-22, доробки P-019 уже на проді)

## Контекст

У шухляді «Локальні фільтри» число біля категорії рахує **усі** оголошення пошуку в БД, а «Всього» — лише ті, що
покаже таблиця (без прихованих локальними фільтрами й без нерелевантних за AI). Людина очікує, що сума чисел категорій
дорівнює «Всього», — вони не сходяться (приклад «mac mini»: категорії ≈ 1 375, «Всього» 546). Рішення людини
(2026-10-22): 1А 2А 3А (через підказку) 4А.

| # | Що | Рішення |
| --- | --- | --- |
| 1 | Число біля категорії | Скільки оголошень цієї гілки покаже таблиця, **якщо обрати цю категорію**: враховані решта локальних фільтрів (ціна, місто, продавець, плюси/мінуси — поточні, незбережені) і перемикачі «показати приховані/нерелевантні»; фільтр категорій сам себе не враховує. Без обраних категорій сума коренів + «Без категорії» = «Всього» |
| 2 | Число OLX | Прибрати з рядка; показувати в підказці при наведенні на число |
| 3 | «Всього» | Більший шрифт і помітніший блок; у підказці — «з N у базі», скільки приховано і чим (нерелевантні / локальні фільтри) |
| 4 | Згорнути / розгорнути | Одна кнопка-перемикач над деревом: згортає чи розгортає всі гілки |

## Файли

- `web/src/utils/categoryCounts.ts` — лічильник лише з переданого (уже відфільтрованого) масиву.
- `web/src/utils/localFilters.ts` — оцінка фільтрів без групи категорій (параметр/хелпер).
- `web/src/hooks/useCategoryTree.ts` — приймає предикат видимості (поточні фільтри + перемикачі шуму).
- `web/src/components/searches/local-filters/CategoryFilter.tsx` — один лічильник, OLX у підказці, легенда, кнопка 4.
- `web/src/components/searches/SearchFiltersDrawer.tsx` — «Всього»: розмір, розбивка в підказці; передає предикат.
- Доки: `docs/business-rules.md` / `docs/architecture.md` — якщо там описано пару «наших / OLX» (перевірити Grep).

## Test-cases

ручні test-cases.

Ручні (людина; локально, `npm run dev` → http://localhost:5173; платних дій немає):

| # | Що зробити | Що маєш побачити |
| --- | --- | --- |
| 1 | У рядку пошуку «mac mini» — кнопка «Фільтри» (воронка) | Шухляда «Локальні фільтри — mac mini»; «Всього» — велике число; біля кожної категорії одне число |
| 2 | Склади числа кореневих категорій (+ «Без категорії», якщо є) | Сума = «Всього» |
| 3 | Наведи мишу на «Всього» | Підказка: скільки в базі, скільки приховано нерелевантних і скільки — фільтрами |
| 4 | Наведи мишу на число біля «Електроніка» | Підказка з числом на OLX |
| 5 | «Діапазон цін» → «макс» = 500 (не зберігати) | «Всього» і числа категорій зменшились; сума коренів знову = «Всього» |
| 6 | Постав галочку біля «Електроніка» | «Всього» = числу біля «Електроніка» |
| 7 | Над деревом — кнопка «Згорнути все» | Усі гілки згорнуті; кнопка стала «Розгорнути все»; клік — усі розгорнуті |
| 8 | Закрий шухляду без «Зберегти» | Таблиця не змінилась |
