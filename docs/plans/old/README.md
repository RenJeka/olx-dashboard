# Архів виконаних планів

Плани тут — **історичний знімок** на момент виконання: шляхи до коду в них можуть не збігатися
з поточною структурою (після рефакторингів), і `npm run docs:check` їх свідомо не перевіряє —
перевіряються лише посилання на документи. Актуальний стан коду — [`../../structure.md`](../../structure.md)
і [`../../architecture.md`](../../architecture.md); інваріанти — [`../../../AGENTS.md`](../../../AGENTS.md).

Кожен план має рядок `> **Статус:** ✅ виконано (дата) · примітки` під заголовком. Дата — остання
змістовна правка плану (≈ завершення). Невідмічені пункти в архівних планах — здебільшого ручні
test-cases, які не прогонялись або не фіксувались; це вказано в примітці статусу.
