# Зрозумілі лічильники у фільтрі «Категорії»

> **Статус:** ✅ виконано (2026-10-22) · ручні test-cases 1–9 пройдено людиною (локально, копія проду від 2026-10-22)

## Контекст

У шухляді «Локальні фільтри» число біля категорії рахує **усі** оголошення пошуку в БД, а «Всього» — лише ті, що
покаже таблиця (без прихованих локальними фільтрами й без нерелевантних за AI). Людина очікує, що сума чисел категорій
дорівнює «Всього», — вони не сходяться (приклад «mac mini»: категорії ≈ 1 375, «Всього» 546). Рішення людини
(2026-10-22): 1А 2А 3А (через підказку) 4А.

| # | Що | Рішення |
| --- | --- | --- |
| 1 | Число біля категорії | Скільки оголошень цієї гілки покаже таблиця, **якщо обрати цю категорію**: враховані решта локальних фільтрів (ціна, місто, продавець, плюси/мінуси — поточні, незбережені) і перемикачі «показати приховані/нерелевантні»; фільтр категорій сам себе не враховує. Без обраних категорій сума коренів + «Без категорії» + «Інші категорії» = «Всього» |
| 2 | Число OLX | Прибрати з рядка; показувати в підказці при наведенні на число |
| 3 | «Всього» | Більший шрифт і помітніший блок; у підказці — «з N у базі», скільки приховано і чим (нерелевантні / локальні фільтри) |
| 4 | Згорнути / розгорнути | Одна кнопка-перемикач над деревом: згортає чи розгортає всі гілки |

**Знахідка під час реалізації (агент, упевненість висока):** частина оголошень має категорію, якої немає в дереві
фільтра (дерево — кешований facet OLX за основним запитом). У «mac mini» на копії проду 2026-10-22 таких 466 з 1 841
(видимих без фільтра категорій — 103). Без окремого рядка сума коренів ≠ «Всього», тому під деревом додано рядок
«Інші категорії: N» (обрати їх у дереві не можна). Звідки такі категорії — не з'ясовано.

## Файли

- `web/src/utils/categoryCounts.ts` — лічильник лише з переданого (уже відфільтрованого) масиву; `shownCount`
  замість `localCount`; `countOutsideTree`.
- `web/src/utils/localFilters.ts` — `withoutCategoryFilter` (фільтри без групи «Категорії»).
- `web/src/utils/listingVisibility.ts` — `previewHideReason` (прев'ю незбережених фільтрів поверх `passesNoiseFilters`).
- `web/src/hooks/useCategoryTree.ts` — приймає готовий масив видимих оголошень (замість предиката; рахує шухляда).
- `web/src/components/searches/local-filters/CategoryFilter.tsx` — один лічильник, OLX у підказці, легенда, кнопка 4,
  рядок «Інші категорії».
- `web/src/components/searches/SearchFiltersDrawer.tsx` — «Всього»: розмір, розбивка в підказці; один прохід по
  оголошеннях для «Всього» і бази дерева.
- Доки: `docs/architecture.md`, `docs/structure.md` (у `business-rules.md` пари «наших / OLX» немає).

## Test-cases

Автоматичні: у `web/` немає Vitest (тести лише в `server/`) — зміна суто фронтова, перевірка `npm run typecheck` +
ручні test-cases. Очікувані числа нижче агент порахував тим самим кодом на локальній копії проду від 2026-10-22
(перемикачі «показати приховані / нерелевантні» над таблицею — вимкнені).

Ручні (людина; локально, `npm run dev` → http://localhost:5173; платних дій немає):

| # | Що зробити | Що маєш побачити |

| 1 | Ліва панель → рядок пошуку «mac mini» → «⋮» → «Фільтри» | Шухляда «Локальні фільтри — mac mini»; праворуч у шапці — помітний блок «Всього **397**»; біля кожної категорії одне число (без «/ OLX»); біля «Електроніка» — 397 |
