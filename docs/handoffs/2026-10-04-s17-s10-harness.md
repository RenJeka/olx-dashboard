## Decisions (і чому)

- **S17 — лише замір, лагодження не зараз** (людина: не найважливіша задача). Варіанти лагодження → P-010, P-008;

- **S10 — варіант «а»** (людина): при вичерпаній видачі оголошення без `last_refresh_at` теж кандидати на
  auto-disable (повна видача — сама доказ); документацію підігнано під код. Хибно вимкнене повертається саме:
  наступний GraphQL-скан, що бачить його активним, ставить `disabled → new` (лише `status_source='auto'`; нотатка
  `auto-disabled…` лишається; вручну «відхилене» → «вимкнене» не повертається).
- **Dependabot** (людина): ≈ раз на 2 тижні (cron `0 7 1,15 * *`, Київ — «кожні 2 тижні» Dependabot не вміє); npm —
  лише minor/patch групою, major — вручну (P-012); дії CI — і major. Ubuntu 26 на CI з 19.10 — нічого не робити.
- **Дії CI → `v7`** (P-004): зламів для нас у `v5`–`v7` немає (явний `cache: npm`, GitHub-hosted раннер).
- **`@types/node`** — лише разом зі зміною Node на проді (зараз 22).
- **H5 runbook** — у `deploy-render-turso.md`, а не окремим файлом (деплой-факти в одному місці).

## Dead ends — не повторювати

- **Гіпотеза «гальмує CPU 0,1 ядра»** (минула сесія): ліміт 0,15, CPU зайнятий ~2,4 с із 17 с → вузьке місце —
  очікування даних Turso. Платний Render дав би мало.
- **Відстань Render ↔ Turso:** Франкфурт ↔ `aws-eu-west-1` — не причина.
- **Скриптова заміна без перевірки** — пропущена заміна в логах S17 і видалений чужий рядок у `current.md` →
  `docs/instructions/scripted-edit-assert.md`.
- **Smoke на 3001** — там `tsx watch` людини → `docs/instructions/local-dev-port-busy.md`.
- **`npm install` після Dependabot** змінює lock-файл службовими `"peer": true` → `docs/instructions/npm-lockfile-peer-flags.md`.
- **Цикл `until gh pr checks …` в одній команді з `gh pr create`** раз завис на 400 с (CI вже був зелений);
  причину не з'ясовано — чекати окремою командою з номером PR.
