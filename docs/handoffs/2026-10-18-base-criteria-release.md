## Dead ends — не повторювати

- **Turso MCP OAuth: вставити callback-URL пізно** → «No OAuth flow is in progress»: потік протермінувався. Нове
  посилання (`authenticate`) і callback одразу; часто вхід завершується сам, коли сторінка `localhost:<port>` відкрилась.
- **Твердження «`main` захищений»** — хибне: захисту гілки немає (`gh api …/branches/main/protection` → 404). Прямий
  пуш у `main` можливий, але це деплой — лише з «так».
