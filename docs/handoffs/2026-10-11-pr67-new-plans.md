## Decisions (і чому)

- **Порядок:** спершу [criteria-auto-group](../plans/criteria-auto-group.md), далі
  [llm-haiku-prompt-audit](../plans/llm-haiku-prompt-audit.md) (людина: «так, починай з автогрупування»).
- **Нова сесія для автогрупування** (агент, людина доручила вибір): контекст цієї розмови вже стискався, план
  самодостатній.
- **Гілка:** питання відкрите — у плані агент пропонував продовжити в `feat/criteria-categories` (PR #67 оновиться)
  або злити #67 і почати нову гілку; людина не відповіла.
- **Автогрупування** (план, без змін від людини): кнопка «Згрупувати автоматично» поруч із «Згенерувати», LLM повертає
  `{"groups":[{name, members}]}`, перевірка членів у коді, вікно вибору груп і членів, застосування однією транзакцією —
  `merges: [{from,to}]` у `POST /criteria/remap`.
- **Аудит промптів:** гіпотези «протилежних» пунктів — H1 (генерація, висока), H2 (немає списку протилежного режиму,
  середня), H3 (заперечення «не …» проходить перевірку evidence, середня); замір — `npm run llm:eval` із суддею Sonnet 5.5,
  ціль ≤ 2 % помилкової полярності, precision ≥ 95 % (пропозиція агента, людина не уточнювала).
