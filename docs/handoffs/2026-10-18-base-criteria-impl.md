## Decisions (і чому)

Людина:

Агент (рішення за людину; ціна, якщо хибне):
- Виконавці не комітять; diff задачі — між знімками робочої теки, коміт зі знімка ([sdd-without-commits](../instructions/sdd-without-commits.md)) — без ціни.
- Фільтр «Категорії» з «крім» → виключення з підрахунку автокатегорії — неточна категорія лише для таких фільтрів.
- Фільтр «Категорії» не збігся з оголошеннями → категорія з усіх оголошень — рідко категорія поза фільтром.
- `POST /api/categories/collect` синхронний, паралельний або під час скану → 409 — довгий HTTP-запит (~1 хв).
- Злиття: базові від кореня до листка, далі власні; збіг назви — перемагає найвищий базовий, синоніми зливаються —
  у підказці предок, а не листок.
- Пункт, вимкнений у наборі категорії, не успадковується — пошук не може його увімкнути.
- Злитий («поглинутий») власний пункт зберігається прихованим, стан повторює базовий; перейменування базового
  переписує й власні пункти пошуків (виправлення фінальної рецензії; первинне рішення «зберігати увімкненим» скасовано).
- Remap у категорії — лише власних пунктів категорії; успадкований → 400.
- Чернетка категорії: відкинути наявні → протилежний режим → обрізати до `BASE_CRITERIA_DRAFT`.
- Позначка «є набір» оновлюється з відповіді сервера, без перечитування дерева (Turso).
- Скан без нових оголошень не перераховує категорію пошуку, якщо вона вже є (Turso).
- `llm:eval`, `jev:probe`, `jev:pilot` — поза скоупом, бачать лише власні пункти (P-019).

## Dead ends — не повторювати

- **Скрипти скіла SDD (`task-brief`, `review-package`)**: не знаходять українські заголовки «Задача N» і вимагають
  комітів. Замість них — власні `brief.sh` / `snap.sh` / `pkg.sh` у `.superpowers/sdd/base-criteria/` (gitignored).
- **Зупинити чужий `node`-процес (`Stop-Process`)**: auto-mode блокує. «Зайвий» `tsx`-процес виявився давнім
  `npm run dev` людини (перезапустився від правки `index.ts`).
- **Пункти меню «⋮» у wmux-браузері**: ні клік, ні `ArrowDown` не працюють стабільно ([wmux-browser-ark-menu](../instructions/wmux-browser-ark-menu.md)).
- **Python-heredoc з `r'''…'''` у Git Bash**: падає «unexpected EOF»; великі правки доків — інструментом Edit.
