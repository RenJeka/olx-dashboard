# Нова інструкція

Викликай одразу, як пастку виявлено, або наприкінці сесії за пропозицією `session-close`.

1. Пошукай (Grep по `docs/instructions/` і доках із карти `AGENTS.md`), чи тема вже є. Є — онови
   наявний файл. Доменна механіка (скани, статуси, OLX, AI, схема) живе у своїх документах
   (`business-rules.md`, `olx-api.md`, `ai-flow.md`…) — туди, а не в інструкцію.
2. Ім'я: латиницею, kebab-case, за змістом, не за датою.
3. Чернетка за [шаблоном](../../docs/templates/instruction.md): коли застосовувати, що робити, чого не
   робити, як перевірити. Факти з інших документів не копіювати — посилатися.
4. Секретів і кількостей, що застаріють, не записувати ([rules](../../docs/rules.md)).
5. Покажи чернетку й збережи після підтвердження.
6. Додай рядок у [`docs/instructions/README.md`](../../docs/instructions/README.md): файл і коли
   читати, одним реченням.
7. Якщо це процедура з кроками — запропонуй скіл (`skill-from-instruction`).
8. `npm run docs:check` — 0 битих посилань.
